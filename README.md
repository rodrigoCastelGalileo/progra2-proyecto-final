# Sistema de Gestión de Tickets de Soporte

Proyecto final de Programación 2 desarrollado en Java.
Grupo formado por:

- Rodrigo Castellanos
- Alfredo Sofio
- Henrik Solares

El sistema permite registrar usuarios y técnicos, crear tickets de soporte, asignarlos, cambiar su estado, modificar información, registrar soluciones y realizar distintas consultas.

## Tecnologías

- Java
- Programación Orientada a Objetos
- ArrayList
- Consola

## Funcionalidades principales

- Registro de usuarios
- Registro de técnicos
- Creación de tickets
- Asignación de técnicos
- Cambio de estado
- Modificación de tickets
- Registro de soluciones
- Consultas por ID, estado, usuario y técnico
